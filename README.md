# THE-LAST-ROOM
A 2D psychological horror survival game built with Python &amp; Pygame.

🔦 What happens when you combine Python with psychological horror? 🕯️

I’m excited to share my latest project: THE LAST ROOM – a cinematic 2D horror survival game built entirely from scratch using Python.

🎮 About the Game:
You wake up in an abandoned mansion with no memory. To escape, you must navigate through 50 procedurally generated levels, solve puzzles, find story clues, and survive the entity hunting you down. The game features a dynamic Fear system, hiding mechanics, and jump scares.

🛠️ Tech Stack & Technical Highlights:

Language & Engine: Python (Pygame & NumPy).
Procedural Generation: Maps, furniture, and levels are dynamically generated on the fly.
Procedural Audio: Every sound effect (heartbeat, footsteps, whispers, jump scares) is synthesized in real-time using NumPy arrays. Zero external audio files used!
Advanced Lighting: Custom-built pseudo-3D dynamic lighting, flashlight cones, and volumetric dust particles.
AI Mechanics: Ghost enemy with a state-machine (Patrol, Investigate, Chase) that reacts to player noise and line of sight.
Web Ready: The code is structured to be compiled to WebAssembly (HTML5) using Pygbag.
💡 The biggest challenge? Building a fully atmospheric, interactive horror experience while managing real-time audio synthesis, dynamic lighting, and AI pathfinding all within Python.
